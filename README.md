# Nehal Choudhary Portfolio

Personal portfolio site built with Next.js, Tailwind CSS, and Framer Motion.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

- Site copy and project data: `src/data/site.ts`
- Resumes: `public/resumes/`

## Stack

- Next.js App Router
- Tailwind CSS v4
- Framer Motion
- Lucide icons
